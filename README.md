##  COUNTER 🔢

A simple counter that increase and decrease count. It also has a reset button that set the count back to 0.Along with **HTML**, **CSS** it has a **javascript**.



## FEATURES 🚀

1. increase, decrease and reset btn.
2. count display on screen.
  
---

## Technology used ⚒️

- **HTML**                        -> for structure
- **CSS**                         -> for styling
- **JavaScript**                 -> for interactive layout
